CÀI ĐẶT DATABASE ONLINE + API NGÂN HÀNG & ĐƯA LÊN GITHUB MIỄN PHÍ TỪ A-Z

Vì GitHub Pages chỉ chứa file tĩnh, để mọi khách hàng vào từ điện thoại/máy tính khác nhau đều nhìn thấy chung Kho Key `trollmodz`, đăng ký tài khoản và nạp tiền tự động Online, bạn chỉ cần kết nối với Firebase Firestore (Miễn phí 100% của Google) theo 4 bước cực dễ dưới đây:

BƯỚC QUAN TRỌNG: NHÚNG CẤU HÌNH FIREBASE DATABASE ONLINE VÀO FILE INDEX.HTML

Dán đoạn `firebaseConfig` (lấy miễn phí tại console.firebase.google.com) vào ô dưới rồi bấm Lưu & Tải file index.html. Khi up file đó lên GitHub, shop của bạn sẽ chạy Online 100% trên toàn cầu!

1

Tạo Database Online miễn phí (Firebase)

  1. Vào console.firebase.google.com bằng Gmail Bấm Create a project (đặt tên `nkcheat`).
  2. Trong trang chính Project, bấm biểu tượng Web (</>) đặt tên rồi copy đoạn firebaseConfig = { ... } dán vào ô bên trên.
  3. Menu trái chọn Build → Authentication → Sign-in method Bật Anonymous (Enable).
  4. Menu trái chọn Build → Firestore Database → Create database Chọn Start in test mode là xong!
2

Cách lấy API Ngân hàng nhận tiền thật mới cộng

  1. Đăng ký miễn phí tại SePay.vn, Casso.vn hoặc Web2M.com rồi liên kết tài khoản ngân hàng nhận tiền của bạn.
  2. Nếu dùng SePay / Casso: Bạn có thể kết nối vào Google Sheet + Apps Script (chọn Deploy as Web App → Anyone) để lấy đường link API JSON, hoặc dán trực tiếp link API lịch sử giao dịch vào mục Quản Trị Admin → URL API.
  3. Khi khách chuyển khoản có nội dung mã lệnh (VD: NKC849201), API trả về giao dịch khớp số tiền + nội dung thì web mới tự động cộng tiền!
3

Đưa file index.html lên GitHub

  1. Vào github.com đăng ký tài khoản Bấm dấu (+) → New repository.
  2. Đặt tên nkcheat, chọn Public rồi bấm Create repository.
  3. Bấm uploading an existing file, kéo file index.html (vừa tải ở hộp phía trên) vào rồi bấm Commit changes.
4

Bật tên miền GitHub Pages & Đăng nhập Admin

  1. Trong kho chứa GitHub, vào Settings → Pages.
  2. Mục Branch đổi None thành main rồi bấm Save. Sau 1 phút web của bạn sẽ online tại https://ten-ban.github.io/nkcheat/.
  3. Đăng nhập tài khoản chủ shop: admin / mật khẩu admin123 (nhớ đổi mật khẩu Admin ngay trong bảng Quản trị để bảo mật tuyệt đối!).
